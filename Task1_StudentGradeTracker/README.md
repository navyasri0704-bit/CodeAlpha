# 📚 Student Grade Tracker

## 📌 Project Overview

Student Grade Tracker is a Java console-based application developed using Object-Oriented Programming (OOP) concepts. It helps users manage student records by allowing them to add, search, update, delete, and display student information. The application also calculates average, highest, and lowest marks and stores student records in a text file using Java File Handling.

---

## 🚀 Features

- ➕ Add Student
- 📋 Display All Students
- 🔍 Search Student by Name
- ✏️ Update Student Marks
- ❌ Delete Student Record
- 📊 Calculate Average Marks
- 🏆 Display Highest Marks
- 📉 Display Lowest Marks
- 📑 Generate Summary Report
- 💾 Save Records to `students.txt`
- 📂 Load Records Automatically at Startup

## ▶️ How to Run

1. Download or clone the project.
2. Open the project in **VS Code**, **IntelliJ IDEA**, or **Eclipse**.
3. Compile all Java files.
4. Run `Main.java`.
5. Use the menu to manage student records.
