# 🤖 Artificial Intelligence Chatbot

## 📌 Project Overview

The **Artificial Intelligence Chatbot** is a Java console application that simulates a simple AI chatbot using **rule-based Natural Language Processing (NLP)**. The chatbot interacts with users by recognizing keywords and providing predefined responses to frequently asked questions.

This project demonstrates the fundamentals of Artificial Intelligence concepts, Object-Oriented Programming (OOP), and Java programming.

## ▶️ How to Run

### Requirements

- Java JDK 17 or above
- VS Code / IntelliJ IDEA / Eclipse

### Steps

1. Install Java JDK.
2. Create a new Java project.
3. Create a file named **Main.java**.
4. Copy and paste the chatbot source code.
5. Save the file.
6. Compile the program:

```bash
javac Main.java
```

7. Run the program:

```bash
java Main
```

## 🧠 How the Chatbot Works

1. The user enters a question.
2. The chatbot converts the input into lowercase.
3. It searches for matching keywords.
4. If a keyword is found, an appropriate response is displayed.
5. If no keyword matches, the chatbot displays a default response.
6. The conversation continues until the user types **bye**.
